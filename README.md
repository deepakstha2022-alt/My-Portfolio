# Secure Cyber Portfolio (HTML/CSS/JS)

## Files
- `index.html`
- `styles.css`
- `script.js`

## Run
Open `index.html` in a browser.

## Features
- Neon cybersecurity dark theme
- Animated loading screen + “Access Granted”
- Matrix-style falling code background (canvas)
- Particle/network connection animation (canvas)
- Typing animations (hero + simulated terminals)
- Scroll-triggered reveal
- Glowing buttons + neon borders
- Hacker-style floating binary/cursor/scanlines
- Animated skill progress bars + heatmap activity
- Terminal-styled contact form submission (simulated)
